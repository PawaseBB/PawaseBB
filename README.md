# Bhushan Pawase Portfolio https://pawasebb.github.io/PawaseBB/

## Overview
This is a personal portfolio website for Bhushan Bhalchandra Pawase, a software developer specializing in web applications, REST APIs, full-stack engineering, and modern tooling.

## Features
- Responsive landing page with hero section
- Dark/light theme toggle
- Animated cursor and reveal-on-scroll effects
- Sticky navigation with section highlighting
- Project showcase with featured work
- Skills overview with technology badges
- Experience timeline and education summary
- Contact form opens Gmail with a pre-filled message

## Technologies
- HTML5
- CSS3
- JavaScript
- Google Fonts

## Getting Started
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Ensure `style.css`, `script.js`, and `bhushan-img.png` are in the same directory as `index.html`.

## File Structure
- `index.html` — Main portfolio page
- `style.css` — Site styling and layout
- `script.js` — Theme switcher, scroll interactions, form handling, and cursor animation
- `bhushan-img.png` — Profile image used in the hero section
